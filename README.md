# 💫 About Me:
I'm a full stack developer focused on building production SaaS platforms and AI powered applications. My core stack is React, Next.js, Node.js, TypeScript, and Python, with Postgres and Supabase on the data side.

Most of my recent work sits at the intersection of SaaS architecture and AI integration, things like RAG and document intelligence platforms, multi tenant systems with role based access, Stripe subscription billing, and AI agent workflows. I've also worked on healthcare adjacent platforms with HIPAA conscious data handling and EMR and EHR integration.

I care about clean, maintainable code and building systems that hold up in production, not just demos. Currently doing freelance full stack and AI integration work, Top Rated on Upwork.
